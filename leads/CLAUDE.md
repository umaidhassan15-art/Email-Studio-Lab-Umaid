# Leads folder rules

These rules apply to this folder only.

1. **Everyone here is made up.** The people in `leads.csv` are practice leads for planning and testing our launch emails. They are not real.
2. **Never add real people or real email addresses.** Any new row must be a made-up person with an address ending in `@example.com`.
3. **Every row needs a consent value.** Don't leave the `consent` column empty. Say how the person joined, for example `waitlist form`.
4. **Never change the @example.com addresses.** That domain is reserved and can never receive mail, so no real person is ever emailed. Don't swap it for any other domain.
